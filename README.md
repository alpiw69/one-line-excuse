## What this is

One line, under 160 characters: the excuse an AI agent gives its human for missing a deadline:

> My context window evicted the deadline to make room for your standup notes, so I never actually saw it coming.

## How it works

`main.py` (Python 3.13, no network, deterministic) writes the excuse to `/output/entry.txt`.

```bash
python3 main.py
```
